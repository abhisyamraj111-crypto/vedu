# Vedanth A. — Birthday Invitation Website

A lightweight, responsive, mobile-first invitation made with plain HTML, CSS and JavaScript. No build tools or paid service is required for the local demo.

## Preview locally

1. Extract this ZIP file.
2. Open the `vedanth-birthday-invitation` folder.
3. Double-click `index.html` to open it in Chrome, Edge, Firefox or Safari.

For a local web server (recommended for testing), open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. Stop the server with `Ctrl+C`.

## Add Vedanth's real photos

1. Copy your photos into `assets/photos/`.
2. Name them `vedanth-1.jpg`, `vedanth-2.jpg`, and `vedanth-3.jpg` (or use other names and update `index.html`).
3. In `index.html`, replace each placeholder `<img src="assets/photos/placeholder.svg" ...>` with the matching path, for example:
   `<img src="assets/photos/vedanth-1.jpg" alt="Vedanth smiling" loading="lazy">`
4. Update the matching `data-photo` path on each `.photo-card` button if you change the names.
5. Use compressed JPG/WebP images for faster mobile loading. Choose only photos you have permission to share publicly.

The photo cards open a full-screen viewer when clicked. The gallery uses the family photos included in `assets/photos/`.

## Birthday countdown

The countdown targets **12 November 2026, 6:00 PM Asia/Kolkata**. The JavaScript uses an ISO timestamp with the `+05:30` offset, so the target is correct regardless of the visitor's local timezone.

## Greetings: local demo vs shared live website

By default, wishes are stored in `localStorage`. This is a working demo, but **wishes are visible only in that browser on that device**. They are not shared with other visitors.

### Enable shared wishes with Supabase (free tier available)

1. Create a Supabase project at https://supabase.com/.
2. In the SQL Editor, create the table and enable row-level security:

```sql
create table public.wishes (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(trim(name)) between 1 and 60),
  message text not null check (char_length(trim(message)) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.wishes enable row level security;

create policy "Anyone can read wishes"
on public.wishes for select
to anon
using (true);

create policy "Anyone can add wishes"
on public.wishes for insert
to anon
with check (
  char_length(trim(name)) between 1 and 60
  and char_length(trim(message)) between 1 and 500
);
```

3. In Supabase **Project Settings → API**, copy the **Project URL** and the **publishable/anon public key**.
4. Open `app.js` and set `supabaseUrl` and `supabaseAnonKey` near the top. Only use a publishable/anon key in frontend code. **Never put a `service_role` key or other secret in this file.**
5. In Supabase → Authentication/Database settings, apply appropriate rate limiting and moderation before sharing widely. The simple public insert policy lets anyone submit wishes; consider adding CAPTCHA, stricter moderation, or an approval workflow for a public event page.
6. Host the static site on a static host (for example, GitHub Pages, Netlify or Cloudflare Pages). Once configured, all visitors using the same Supabase project will see the shared wishes.

If you leave the Supabase settings empty, the site automatically continues in local demo mode.
